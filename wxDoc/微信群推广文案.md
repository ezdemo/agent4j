## 版本二：走心长文案（适合朋友圈 / 大群首发）

做了几个月的开源项目，正式拉个交流群。

**Loopra** 是一个纯 Java 17 写的 AI 编码代理——你可以理解成"Java 版的 Claude Code"：

- 它不是一次生成完事，而是像工程师一样**一整轮一整轮地迭代**：读代码 → 推理 → 调工具 → 看结果 → 再推理，直到把活干完
- 改代码前可以开**计划模式**：AI 只读探索、提交方案、你审批之后才动手
- 内置五种**子代理**（探索/实现/测试/审查/方案），复杂任务分而治之
- **人工审批三档可调**，路径边界保护，AI 想越界必须经过你同意
- Web 界面 + Electron 桌面端，Windows / macOS 全平台

最近刚发了 v26.8：内核拆成了三个可独立依赖的 Maven 模块，想把 AI 推理循环嵌进自己 Java 服务的，加一个依赖就行。

🌐 官网：https://loopra.cn（支持中英双语）
💻 GitHub：https://github.com/ezdemo/loopra（MIT 协议）
📦 十秒上手：`irm https://raw.giteeusercontent.com/ezdemo/loopra/raw/main/.release/setup.ps1 | iex`（国内有镜像加速）
