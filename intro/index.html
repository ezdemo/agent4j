六大核心特性

Agent4j 将 LLM 与可扩展工具系统结合，形成自主工作的编码代理

🤖

推理循环

Prompt → LLM → 工具 → 结果 → LLM，自动迭代直到任务完成。实时流式推送每一步的思考和执行过程，全透明可追踪。

🛠️

工具系统

声明式 AgentTool 基类 + Solon @Component 自动注册。支持 MCP 协议、OpenAPI 集成、技能市场在线装/卸。16+ 内置工具开箱即用。

🔀

子代理

隔离执行环境，每个子代理有独立上下文和推理循环。并行处理独立任务互不干扰，由主代理统一调度汇总。

👤

人工审批

HITL 机制：写操作前等待你批准或拒绝。/agree / /deny 快速决策。支持 auto（需确认）和 yolo（直接干）两种模式。

💬

会话管理

多会话创建、切换、搜索、删除。JSONL 格式持久化，会话自动生成标题，每次操作记录 token 用量，透明可审计。

⚡

前缀缓存

系统提示词、工具定义等重复内容直接命中 KV cache。DeepSeek ≥97%，Mimo ≥98% 命中率，输入 token 费用降至 2%~3%。

深入核心能力

从推理到工具，从子代理到审批，Agent4j 提供企业级 AI 代理所需的一切

🤖 推理循环 Reasoning Loop

Agent4j 的核心是一个自动迭代的推理循环。用户给出任务后，LLM 思考、调用工具、观察结果、再思考… 直到任务完成。整个过程流式实时推送。

  • 自动循环 — Prompt → LLM → 工具 → 结果 → LLM，自动迭代
  • 流式输出 — 实时推送思考过程、工具调用和结果
  • 上下文折叠 — 旧消息自动摘要，不机械截断，保留关键信息
  • 消息自愈 — 自动修复被截断的 JSON 和 tool_calls
  • 风暴断路器 — 检测重复工具调用，防止死循环
  • 推理模型支持 — 原生支持展示思考过程

🛠️ 工具系统 Tool System

Agent4j 内置丰富的工具集，并支持无限扩展。继承 AgentTool 基类，定义名称、参数、执行逻辑即可注册新工具。

  • 声明式工具 — 继承 AgentTool 基类，Solon @Component 自动发现
  • MCP 支持 — 接入 Model Context Protocol 服务器
  • OpenAPI 集成 — 任意 OpenAPI 规范自动转成工具
  • 技能市场 — 在线装/卸社区技能
  • Plan Mode — 只读模式，安全规划后再执行

🔀 子代理 Sub-Agent

将复杂任务拆解给多个子代理并行执行。每个子代理拥有独立的推理循环和上下文，互不干扰。

  • 隔离执行 — 独立上下文和推理循环，不串扰
  • 继承工具 — 复制父代理工具集，排除递归 spawn
  • 独立通道 — 子代理输出通过独立事件流推送
  • 用量统计 — 按模型统计 token 消耗，透明可见

👤 人工审批 HITL

Agent4j 在执行写操作前会等待你批准或拒绝，确保每次修改都在你的控制之下。支持快速命令决策。

  • 自动模式 — 写操作前需要确认，安全可靠
  • YOLO 模式 — 直接执行，无需确认，适合信任场景
  • 快速决策 — /agree 批准 / /deny 拒绝，即时响应
  • todo_write — 维护任务清单，跟踪执行进度

💬 会话管理 Session Management

多会话并行管理，每个会话有独立上下文。JSONL 格式持久化，历史数据可追溯、可审计。

  • 多会话 — 创建、切换、搜索、删除，灵活管理
  • JSONL 持久化 — 结构化日志格式，方便检索和分析
  • 自动标题 — 根据对话内容自动生成会话名称
  • 用量统计 — 每次操作记录 token 消耗，成本透明
  • 工作区隔离 — 不同项目的工作区互相独立

🚀 快速开始

一行命令安装，两行配置运行

🪟 Windows PowerShell

# 一行命令安装 Agent4j
irm https://raw.giteeusercontent.com/ezdemo/agent4j/raw/main/.release/setup.ps1 | iex

🍎 macOS / 🐧 Linux bash

# 一行命令安装
curl -fsSL https://raw.giteeusercontent.com/ezdemo/agent4j/raw/main/.release/setup.sh | bash

⚙️ 配置 config.json

首次启动自动生成 ~/.agent4j/config.json，填入 API Key 即可： 

{
  // API 地址
  "baseUrl": "https://api.deepseek.com/v1",
  // API 密钥
  "apiKey": "sk-your-api-key",
  // 模型名称
  "model": "deepseek-v4-flash",
  // 工作区目录（你的项目路径）
  "workspaceDir": "/path/to/your/project",
  // 推理强度: low | medium | high | max
  "reasoningEffort": "high"
}
# 启动 Web 服务
agent4j web 0
