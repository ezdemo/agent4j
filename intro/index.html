// 核心能力

不只是对话，是自主工作

Agent4j 将 LLM 推理与工具系统深度绑定，形成一个能自主完成复杂编码任务的智能代理。

🔄

对话式推理循环

多轮上下文自动保持，流式 SSE 调用 OpenAI 兼容 API。思考过程实时打印，工具调用自动收集分发。

⚡

并行工具执行

CompletableFuture.allOf 并行分发工具调用，最大化吞吐量。非阻塞等待，CAS 替代锁。

🛡️

双断路器防护

StormBreaker（滑动窗口 + JSON 指纹）+ ReasonBreaker（流式循环检测），双保险防止 LLM 死循环消耗 token。

📋

计划模式

Plan Mode — 只读探索代码库，制定执行计划，用户审批后切换执行模式，安全可控。

🧠

上下文折叠

ContextFolding — 长对话语义压缩，将历史消息折叠为摘要，避免上下文窗口溢出。

🔧

消息自愈

MessageHealer — 发送前自动修复消息序列：配对 tool_calls、补充 reasoning、截断过长的 tool 结果。

🕵️

工具调用回收

Scavenger — 从 reasoning_content 中回收因 API 格式问题丢失的 tool_calls，提高调用成功率。

🧬

子代理隔离

SubAgent — 创建独立循环的子代理处理复杂任务，排除递归 spawn 和用户交互工具，结果自动返回。

💾

会话持久化

JSONL 文件存储 + BufferedWriter 缓冲写入 + 定时自动刷入，ReentrantLock 保证线程安全。

📊

Token 用量追踪

精确统计每次 API 调用的 token 消耗，支持缓存命中率分析，帮助优化成本和性能。

🔒

路径穿越防护

所有文件操作通过 resolveSafe() 严格校验路径，杜绝目录穿越攻击，确保工作区安全。

✏️

原子批量编辑

multi_edit — 全验证→全写入→失败回滚，确保跨文件编辑的数据一致性与原子性。

🧠

推理断路器

ReasonBreaker — 流式检测 LLM 思考循环，发现重复推理模式时提前终止，节省 token 消耗。

👤

HITL 人机协同

双模式审批 — 写入操作需确认 + 沙箱越界强制拦截（独立管道），安全可控的人机协作。

📦

Skill 系统 V2

用户可定义可复用的 Skill playbook，支持 inline 和 subagent 两种运行模式，跨会话持久化。

🖥️

多端交付

CLI 命令行 + Web REST API + Vue 3 前端 + Tauri 桌面端，四端统一核心，一次编写处处运行。

// 设计模式

十几种经典模式的Java 实践

每个组件都经过精心设计，追求高内聚低耦合。

不可变前缀 · Caching
PromptPrefix

System prompt + tool specs 跨 turn 不变，最大化 DeepSeek 前缀缓存命中，显著降低延迟。

双断路器 · Circuit Breaker
StormBreaker + ReasonBreaker

StormBreaker 滑动窗口 + JSON 指纹去重；ReasonBreaker 流式检测思考循环。双保险防死循环。

工厂模式 · Factory
Agent4jAgent.Builder

链式 Builder 构建复杂对象，可读性强，支持灵活配置 ModelClient、ToolRegistry 等组件。

观察者模式 · Observer
AgentLoopListener

推理过程、工具调用、用量统计的事件回调，支持实时监控和自定义处理逻辑。

策略模式 · Strategy
ModelClient 接口

可替换的 LLM API 实现，默认 HttpModelClient 支持所有 OpenAI 兼容端点。

命令模式 · Command
ChatCommandRegistry

"/" 命令通过 Solon IoC 自动注册，新增命令只需实现接口标注 @Component。

模板方法 · Template
AgentTool

子类实现 getName/getDescription/getParameters/execute，框架负责调度和生命周期。

缓冲写入 · Buffered I/O
JsonlSessionStore

BufferedWriter 保持打开 + flush() 显式刷入 + 30s 定时刷入，ReentrantLock 保证线程安全。

享元模式 · Flyweight
PromptPrefix

共享 system prompt + tool defs，多个 Agent 实例复用同一不可变前缀，减少内存和构建开销。

沙箱旁路 · ThreadLocal
ToolContext

ThreadLocal 控制沙箱越界权限，HITL 审批通过后临时提升，审批结束自动恢复隔离。

// 快速开始

5 分钟上手运行

只需 JDK 17+、Maven 和一个 OpenAI 兼容的 LLM 端点。

~/.agent4j/config.json 
{
  "baseUrl": "https://api.deepseek.com/v1",
  "apiKey": "sk-your-api-key",
  "model": "deepseek-v4-flash",
  "workspaceDir": ".",
  "editMode": "auto",
  "reasoningEffort": "max",
  "lang": "ZH",
  "hitl": false,
  "disabledTools": [],
  "blockedPaths": [],
  "availableModels": ["deepseek-v4-flash", "gpt-4o", "claude-3.5-sonnet"]
}
终端 · Terminal 
# 1. 克隆项目
git clone https://gitee.com/ezdemo/agent4j.git
cd agent4j

# 2. 编译
mvn compile -pl agent4j-bin

# 3. 运行
mvn exec:java -pl agent4j-bin \
  -Dexec.mainClass="site.sorghum.agent4j.bin.Agent4jApp"

# 首次启动自动创建 ~/.agent4j/config.json
# 编辑 API 配置后重新运行即可
