Core capabilities

不仅能回答，
更能把任务推进到结果。

Loopra 将模型推理与本地工具调用组织为持续循环，在任务完成、需要审批或遇到阻塞前保持工作上下文。

⌕

理解整个工作区

读取、检索与修改都在项目边界内进行。Agent 先建立上下文，再动手处理真实的调用链和依赖关系。

▾ src▾ auth◆ TokenValidator.java◆ AuthInterceptor.java◆ AuthServiceTest.java
↻

持续的推理循环

任务、工具结果与下一步决策连接成循环。无需为每次文件读取和命令输出反复补充上下文。

任务→推理→执行
◆

权限始终清晰

只读、审批与自动三种模式，将高风险调用交给人工确认。路径边界与校验模型提供额外保障。

readgrepbash · 审批
✦

适合长任务的协作状态

Goal、Checklist、会话折叠与项目记忆，让 Agent 在多步骤任务中保留进度、证据和稳定约定。

✓ 定位影响范围✓ 修改与测试 汇总结果

Start local

几分钟，启动你的本地工作台。

从 Gitee 获取发布版本并在本机运行。Desktop 安装包由 GitCode 发布；源码同时提供 Gitee 主仓库与 GitHub 镜像。

查看 Github Releases →
Gitee 源码 ↗ GitHub 镜像 ↗ GitCode Desktop ↗
Install and run

Windows PowerShell

PS> irm https://raw.giteeusercontent.com/ezdemo/loopra/raw/main/.release/setup.ps1 | iex

macOS / Linux

$ curl -fsSL https://raw.giteeusercontent.com/ezdemo/loopra/raw/main/.release/setup.sh | bash

启动服务

$ loopra web 0

Serving Loopra at http://localhost:5210
